# This travel website sample  
## Link https://cstrp.github.io/Travel_site/
### This project uses technologies such as:
**figma - free layout used for site layout**

**html, css - the main component of this site (the adaptive model was not implemented)**

**js - mainly to create the effect of the appearance of blocks when scrolling the site, an infinite like counter, and a custom video player**

**svg - adding, applying filters**

**amination - animations, transitions, shadows, backgrounds, filters.**
