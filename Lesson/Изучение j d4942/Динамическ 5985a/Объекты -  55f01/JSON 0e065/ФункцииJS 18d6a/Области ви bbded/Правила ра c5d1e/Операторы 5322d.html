Операторы

Оператор - это встроенная функция

  • Операторы (индексная, префиксная и постфиксная записи)

    Операнды

    • Унарные (у унарных операторов всегда один операнд (аргумент)

      a++

      +a

      delete obj.a

      typeof a (а - операнд)

      new Object () (создает новый экземпляр объекта)

      • Бинарные (у бинарных операторов всегда два операнда (аргумента)

        = присвоение

        + сложение

        += увеличение значения (присвоение увеличение)

        === сравнение (по типу и значению) (строгое)

        && оператор “И”

    • Операторы

      Арифметические + - * /

      Сравнения === !== <= >=

      • Логические ! && || !-не &&-и ||-или

        ! всегда возвращает значение типа boolean

        && || всегда возвращают значение одного из операндов

      Присваивания =

    • Текстовые операторы

      typeof

      instanceof

      new

      delete

    • Инфиксная запись

      a = true присвоение

      a + b сложение

      a += 5 присвоение увеличение

      a || b или

      a > b больше

      • Префиксная запись (т.е. перед)

        ++а

        delete obj.a

        typeof a пишется только в таком формате

      • Постфиксная запись (т.е. после)

        a++

        myFunction()

      Приоритетность операторов (визуально можно ставить скобки для разделения последовательности) - по желанию (необходимости) (https://developer.mozilla.org/ru/docs/Web/JavaScript/Reference/Operators/Operator_Precedence)

    • Ложные значения (т.е. дают false)
      • boolean(value) > false их несколько
        1. false
        1. 0
        1. ‘’ - пуская строка (не пуская true)
        1. undefined
        1. null

    Оператор ! (не) (отрицание) чаще всего используется в условных конструкциях

    && оператор “И” || оператор “ИЛИ” являются операторами короткого замыкания

    выражение 1 && выражение 2; Если выражение 1 ложно, то выражение 2 не выполняется (игнорируется) возвращается результат выражения 1

    выражение 1 || выражение2; Если выражение 1 истинно, то выражение 2 не выполняется (игнорируется) возвращается результат выражения 1
