Классы и прототипы

Синтаксис классов появился в ES6, ключевое слово class..

Классы позволяют создавать прототипы для объектов, на основании прототипов создаются экземпляры, которые имеют собственные свойства и методы. Экземпляры наследуют свойства и методы прототипов

Наследование по цепочке? 

class Comment {
  //? коструктор и апвоут - методы
  constructor (text) {
    this.text = text; //? this указывает на экземпляр класса
    this.votesQty = 0;
  }
  upvote () {
    this.votesQty += 1;
  }
  downvote () {
    this.votesQty -= 1;
  }
}

const comment = new Comment('Комментарий'); //? создание экземпляра класса? с собственными свойствавми
// console.log(comment);

// comment.upvote(); //? наследует все методы объекта

//? comment > Coment > Object - цепочка прототипов

//* проверка принадлежности оператор 'instanceof'

comment instanceof Comment; //? true
comment instanceof Object; //? true

comment.upvote(); //? вызов метода? (методы можно вызывать многократно)
comment.upvote(); // ? увеличение значения переменной
console.log(comment.votesQty);

comment.downvote(); //? уменьшение значения переменной
console.log(comment.votesQty);

Расширение других классов
class NumbersArray extends Array { //? Array родительский коструктор вызовется автоматически
  sum () { //? коструктор не нужен при расширении, т.к. он унаследован от родителя
    return this.reduce((acc, item) => acc + item, 0); //? reduce - метод массива доступен
  }
}

const myArray = new NumbersArray(1, 4, 12);

// console.log(myArray.sum()); //? 17
console.log(myArray);
myArray.sum(); //? 17
